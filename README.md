# 🧊 ภูเขาน้ำแข็งในใจ — Satir Iceberg Interactive

เว็บไซต์ให้ผู้ชมละคร “ดูไป ดำน้ำไป” — ค่อยๆ เปิดภูเขาน้ำแข็ง (Satir Iceberg Model) ของคนไข้ทีละชั้น
ตามฉากของละคร โดยตอบคำถามแบบเลือกช้อยส์ระหว่างดู

## วิธีเล่น
1. 🎭 เมื่อฉากเริ่มบนเวที กด “ฉากนี้เริ่มแล้ว”
2. 🫧 เมื่อได้ยินประโยคสำคัญ เลือกคำตอบว่าเป็นชั้นไหนของภูเขาน้ำแข็ง
3. 🧊 ตอบถูก = เปิดชั้นใหม่ แตะแต่ละชั้นเพื่อดูสิ่งที่ค้นพบ

## ชั้นของภูเขาน้ำแข็ง
พฤติกรรม → ความรู้สึกทางกาย → อารมณ์/ความรู้สึก → ความรู้สึกต่อความรู้สึก → ความคิด/มุมมอง → ความคาดหวัง → ความปรารถนา → ✨ ตัวตน (Self)

ทั้งเว็บอยู่ในไฟล์ `index.html` ไฟล์เดียว เปิดได้เลยหรือโฮสต์ด้วย GitHub Pages
